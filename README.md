# Curso-para-crian-a-de-sites
Curso completo para aprender a criar sites
<
    <div class="aula">
        <h2>📚 Aula 1 — O que é um site?</h2>

        <p>
            Um site é uma página que pode ser acessada pela internet.
            Ele pode apresentar textos, imagens, vídeos, botões e muito mais.
        </p>

        <p>
            Para começar a criar sites, vamos aprender três tecnologias:
        </p>

        <ul>
            <li><strong>HTML</strong> — estrutura da página.</li>
            <li><strong>CSS</strong> — aparência e estilo.</li>
            <li><strong>JavaScript</strong> — interações e funções.</li>
        </ul>
    </div>

    <div class="aula">
        <h2>💻 Aula 2 — Conhecendo o HTML</h2>

        <p>
            HTML é usado para criar a estrutura de uma página.
        </p>

        <p>Exemplo:</p>

        <div class="exemplo">
            <code>
                &lt;h1&gt;Meu primeiro site&lt;/h1&gt;
            </code>
        </div>

        <p>
            O código acima cria um título na página.
        </p>
    </div>

    <div class="aula">
        <h2>📝 Aula 3 — Criando um texto</h2>

        <p>
            Para criar um parágrafo usamos a tag
            <strong>&lt;p&gt;</strong>.
        </p>

        <div class="exemplo">
            <code>
                &lt;p&gt;Olá! Este é meu primeiro site.&lt;/p&gt;
            </code>
        </div>
    </div>

    <div class="aula">
        <h2>🎯 O que você aprendeu?</h2>

        <ul>
            <li>O que é um site.</li>
            <li>O que é HTML.</li>
            <li>Como criar um título.</li>
            <li>Como criar um parágrafo.</li>
        </ul>
    </div>

    <div class="atividade">
        <h2>🚀 Atividade do Módulo 1</h2>

        <p>
            Crie uma página com:
        </p>

        <ol>
            <li>Um título com seu nome.</li>
            <li>Um parágrafo falando sobre você.</li>
            <li>Uma lista com 3 coisas que você gosta.</li>
        </ol>

        <p>
            No próximo módulo vamos aprender a deixar o site mais bonito
            usando CSS.
        </p>
