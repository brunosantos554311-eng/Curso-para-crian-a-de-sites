Módulo 1 — Primeiros passos para criar sites

📚 Aula 1 — O que é um site?

Um site é uma página que pode ser acessada pela internet. Ele pode apresentar textos, imagens, vídeos, botões e muito mais.

Para começar a criar sites, vamos aprender três tecnologias:

  • HTML — estrutura da página.
  • CSS — aparência e estilo.
  • JavaScript — interações e funções.

💻 Aula 2 — Conhecendo o HTML

HTML é usado para criar a estrutura de uma página.

Exemplo:

<h1>Meu primeiro site</h1>

O código acima cria um título na página.

📝 Aula 3 — Criando um texto

Para criar um parágrafo usamos a tag <p>.

<p>Olá! Este é meu primeiro site.</p>

🎯 O que você aprendeu?

  • O que é um site.
  • O que é HTML.
  • Como criar um título.
  • Como criar um parágrafo.
